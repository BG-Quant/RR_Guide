# RR_Guide
Guidelines for Reproducible Research

## RERITE dashboard

A static dashboard based on the RERITE V0.2 guidelines for authors, editors, reviewers and publishers. It includes role navigation, search, guidance-level filters, expandable topics and the document references. The summary statistic blocks have been removed.

Open `index.html` in a browser to use the dashboard. No installation or build is required; keep `app.js`, `data.js` and `style.css` beside it.

- `index.html`: page structure
- `style.css`: responsive layout and styling
- `app.js`: navigation, filtering and interactions
- `data.js`: guidance text extracted from the supplied document

The wording is retained from the source document. This dashboard presents guidance; it does not certify compliance.
